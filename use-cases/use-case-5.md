# USE CASE: 5 Add new employee details to the database
## CHARACTERISTIC INFORMATION
### Goal in Context
As an HR advisor I want to add a new employee's details so that I can ensure the new employee is paid.

### Scope
Company.

### Level
Primary task.

### Preconditions
We know the employee details.

### Success End Condition
The new employee is added to the database.

### Failed End Condition
The new employee is not added to the database.

### Primary Actor
HR Advisor.

### Trigger
A request for the addition of a new employee is sent to HR.

## MAIN SUCCESS SCENARIO
1. Finance request a new employee be added.
2. HR advisor captures the details of the new employee.
3. HR advisor adds the new employee to the database.

## EXTENSIONS
None.

## SUB-VARIATIONS
None.
